YouTube Analytics ML Project

Overview

This project uses Machine Learning to analyze YouTube video analytics and predict video views.

Objectives

* Analyze YouTube video performance.
* Explore relationships between analytics metrics and views.
* Build a beginner-friendly Machine Learning regression model.
* Compare actual and predicted views using visualizations.

Technologies Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Jupyter Notebook

Model

A regression model is used to predict YouTube video views. Model performance can be evaluated using metrics such as R² and MAE.
